Twitch Message Remover

Легкое расширение для браузера, автоматически скрывающее сообщения пользователя mcl_6667 в чате Twitch.

Скачать расширение (ZIP)

Установка в Google Chrome / Яндекс.Браузер / Edge

  1. Скачайте архив по кнопке выше и распакуйте его в удобную папку на компьютере.
  2. Откройте браузер и перейдите на страницу расширений: chrome://extensions/
  3. В правом верхнем углу включите тумблер «Режим разработчика».
  4. Нажмите появившуюся кнопку «Загрузить распакованное расширение» слева вверху.
  5. Выберите ту самую распакованную папку с файлами расширения. Готово!

Установка в Mozilla Firefox

  1. Скачайте и распакуйте архив с расширением.
  2. Откройте Firefox и введите в адресной строке: about:debugging#/runtime
  3. Нажмите кнопку «Временные расширения» (Load Temporary Add-on...).
  4. В открывшемся окне зайдите в папку с расширением и выберите файл manifest.json.

Неофициальное расширение для комфортного просмотра Twitch.
